Rules: no emojis in app chrome (tabs, headers, buttons, badges, empty states). Emojis people type
(chat, notes, captions, reactions) stay. Stickers use a white die-cut outline + soft shadow and appear
with a small bounce + haptic. Text inside stickers uses Anton / Inter Tight / JetBrains Mono — load those
fonts in the app, or convert text to outlines before shipping.
